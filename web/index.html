Ten tools, zero order buttons
    
It checks. It never trades.

    
No tool can place, change or cancel an order. Your agent asks first, then trades through whatever it already uses.

  

    
check_sell
Before a sale: gain, clean loss or wash sale. For a wash, the ways out. For a loss, the date to wait before buying back.
wash saleclean loss

    
check_buy
Before a buy: would it wash a loss you already took? How much, and the first safe date.
would washclear

    
harvest_candidates
Positions below cost, ranked by estimated tax saved, with swaps that keep you invested meanwhile.
ranked

    
tax_report
Short and long term after wash adjustments, the $3,000 cap, carry-forward.

    
list_positions
Lots, adjusted basis, unrealized, when each turns long-term.

    
import_transactions
Robinhood activity CSV, or date, symbol, side, qty, price.

    
record_trade
Log a fill right after it happens.

    
settings
Strict mode and the tax rates used for estimates.

    
explain_wash_sale
The rule in plain words and what the tool can't see.

    
load_demo
The sample year from this page.

  






  
Substantially identical
    
Same company, same index, same problem.

    
The IRS never published a list. Same stock and share classes are settled. Funds from different issuers on the same index are a grey area, so strict mode treats them as identical.

What it can't see

  
  • Trades in other accounts: an IRA or a spouse's account can trigger the rule too.
  • Options on the same stock.
  • Dividend reinvestments you didn't import.
  • Shares bought in the window and sold again before the loss sale.
